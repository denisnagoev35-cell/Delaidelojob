# Инструменты «Делай Дело» (не сайт)

Генераторы креативов. Шрифт Montserrat (лицензия OFL) лежит в `fonts/` — скопировать рядом с шаблоном.

- `banners/` — баннеры «зарплата + человечек» (1:1, 4:5 — `r2.js`; 9:16 — `r3.js`; шаблон `tpl2.html`).
  Запуск: положить шрифты и картинки в одну папку, `node r2.js` (нужен Playwright).
- `video/` — промо-ролик бота 17 с, 9:16 (`v.html` — анимация, `render.js` — рендер через ffmpeg).
- `bot-images/mk.py` — аватарка и картинка описания бота (Pillow).
- `slava-endcard/mk.py` — плашка концовки клипа «@delaidelojob» под платформы (Pillow + ffmpeg).
- `site-add-bot-cta.py` — вставка блока «Узнать свою зарплату» на страницы сайта.
