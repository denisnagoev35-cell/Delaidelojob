# Бот «Зарплаты HoReCa» (@delaidelo24bot)

Чистый Python 3.10+, без сторонних библиотек. Данные — SQLite в /opt/ddbot/data.

- `texts.py` — все тексты и цифры зарплат (править здесь).
- `bot.py` — логика.
- Ссылки с меткой источника: `https://t.me/delaidelo24bot?start=vk_clip`
- `/stats` — статистика (для ID из ADMIN_IDS).

Обновить: `cd /opt/ddbot && sudo git pull && sudo systemctl restart ddbot`
Логи: `sudo journalctl -u ddbot -n 50 --no-pager`

## Подборка вакансий (тест, только ADMIN_IDS)

`podbor.py`. Каждый новый пост канала разбирается: профессия, город/метро, ставка, график, опыт.
Сначала YandexGPT (если в /etc/ddbot.env есть `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`), что не нашлось — правилами.
Телефоны, @ники и ссылки в YandexGPT не отправляются. Без ключа всё работает на правилах.

- `/podbor` — опрос и подборка за 7 дней.
- `/reparse [дней]` — разобрать старые посты (по умолчанию 14 дней); ручные правки не трогает.
- `/vac N` — что бот понял из поста №N.
- `/mesto N Химки`, `/stavka N 4000-6000 смена` — поправить вручную.
- Если в новом посте нет места или ставки, бот пишет админу с кнопками.

## Рассылка новых вакансий (тест, только ADMIN_IDS)

Под выдачей /podbor — «🔔 Присылать новые вакансии под этот запрос». Новый пост канала разбирается и сразу
отправляется подписчикам, если подходит точно. Не больше 3 сообщений в день; ночью (22:00–10:00 МСК) и сверх
лимита — копится и уходит сводкой в 10:00 и 20:00. Кто не открывал бота 30 дней — спрашиваем, без ответа 3 дня
выключаем. `/testrass` — показать все сообщения рассылки, `/rass` — список подписок.

## Анкеты соискателей (`anketa.py`)

Соискатель заполняет анкету в личке с ботом (`/anketa` или ссылка `?start=anketa`): согласие → имя →
профессия → опыт → место → ставка → график → о себе (без контактов) → фото работ (по желанию) → как связаться.
Бот публикует анкету **без имени и контактов** с кнопкой «📩 Связаться» (`?start=c_<id>`). Работодатель пишет
название заведения и сразу получает контакт, кандидату приходит уведомление, админу — запись о запросе.
Лимит — 5 контактов в день на одного работодателя. Кандидат может удалить анкету и данные кнопкой.

Режим в /etc/ddbot.env: `ANKETA_MODE=test` — только ADMIN_IDS/TESTER_IDS, «публикация» приходит админам в
личку; `ANKETA_MODE=on` — для всех, публикация в `ANKETA_CHAT` (бот должен быть админом чата).

- `/anketas` — последние анкеты с контактами и число запросов.
- `/anketa_pin` — пост с кнопкой «📝 Заполнить анкету» в чат и закреп (в тесте — превью себе).

## Анкеты для работодателей (`EMP_MODE`)

«🏪 Я работодатель» → «📋 Анкеты кандидатов» (или `/kandidaty` для админа): профессия → место → свежие анкеты
за 30 дней без контактов, кнопки «📩 Связаться №…» и «🔔 Присылать новые анкеты». Новая анкета под запрос
приходит сразу; не больше 10 в день, с 22:00 до 10:00 МСК копится и уходит сводкой в 10:00 и 20:00
(в режиме test — всегда сразу). `/empsubs` — список подписок работодателей.

## Дайджест «ТОП-10 вакансий недели» (`digest.py`)

Каждый понедельник в 15:00 МСК бот берёт разобранные вакансии за 7 дней (открытые, со ставкой и местом, без
повторов), выбирает до 10 — профессии вперемешку, внутри профессии сначала где платят больше — и отправляет пост
с обложкой `digest_cover.png`. Название профессии — ссылка на пост вакансии.

Режим в /etc/ddbot.env: `DIGEST_MODE=test` (по умолчанию, и если не задано) — приходит только ADMIN_IDS в личку;
`on` — публикуется в канал, закрепляется без уведомления, прошлый дайджест открепляется (боту нужны права
«Публикация сообщений» и «Закрепление сообщений»); `off` — выключено. Первый запуск после установки текущую неделю пропускает.

- `/digest` — прислать дайджест себе прямо сейчас (в канал не уходит).
- `/digest_pin N` — записать вручную опубликованный дайджест (пост №N): бот открепит его, когда выйдет следующий.

## Напоминание неподписавшимся и «Отправить другу» (26.11)
- `remind.py`: тем, кто посмотрел зарплату и не подписался, — одно напоминание через сутки после последнего действия, 12:00–20:00 МСК. Перед отправкой — проверка подписки через `getChatMember`: кто уже в канале, тому не пишем (отмечаем подписчиком). Курьеры и те, кто не выбирал профессию, не получают. Кнопка «🔕 Не напоминать». Строка «Напоминания» в `/stats`.
- `REMIND_MODE=on` (по умолчанию) · `test` — только админам · `off` — выключено.
- Под полным разбором — кнопка «📤 Отправить другу»: ссылка `t.me/delaidelo24bot?start=share`, в `/stats` источник `share`.

## Зарплаты в калькуляторе по вакансиям канала (26.11)
- `zp.py`: вилка считается по вакансиям канала за 30 дней (без повторов, одна единица — смена/час/месяц, где вакансий больше). Опыт сдвигает вилку: без опыта — вакансии начального уровня (помощник, стажёр, без опыта) или нижняя часть ставок; до года — 25–50% всех; 1–3 года — 25–75%, 3+ — 50–90% без вакансий начального уровня. Сначала по региону, если мало — по всем. Меньше `ZP_MIN` (5) вакансий — прежняя вилка из texts.py. Подпись: «по N вакансиям канала … за 30 дней».
- `ZP_MODE=test` (по умолчанию) — живые цифры видят только админы · `on` — все · `off` — выключено.
- `/zp` (админ) — таблица по всем профессиям: всё / Мск / МО / по опыту / без опыта и сколько вакансий.

## Посты через бота (`posting.py`, 27.11)
Доступ: ADMIN_IDS и `POST_IDS` (по умолчанию 703473452 — помощник; другим админ-командам помощник доступа не получает).
- Переслать боту вакансию (или вставить текст длиннее 60 знаков) → YandexGPT переписывает её своими словами в формате канала:
  хэштег профессии сверху, текст с 📍 💰 🗓, строка «📩 Отклик: …», подвал канала. Чужие хэштеги, ссылки на канал-источник,
  «подписывайся» убираются. Контакты в нейросеть не уходят — бот вынимает их сам (телефоны, почта, WhatsApp, @ники кроме источника и ботов).
- Кнопки превью: ✅ Опубликовать · 🔁 Переписать ещё · ✏️ Исправить (прислать текст целиком, уходит как есть) · 🖼 Обложка · ❌ Отмена.
  В канал — только по кнопке. После публикации пост сразу разбирается для подборки и рассылки; второму человеку приходит уведомление.
- Обложки: по умолчанию пост без обложки, под превью кнопка «🖼 Обложки» — наши 10 из папки `covers/`
  (кальянщик, бариста, бармен, официант, повар, курьер, хостес, администратор, менеджер, общая «Вакансия») и «🚫 Без обложки».
  Подходящая отмечена ⭐ и стоит первой (администратор/менеджер — по началу текста, иначе по профессии, иначе общая).
  Встроенная грузится с диска один раз, дальше по file_id. Новая обложка — файл в `covers/` + строка в `BUILTIN` (posting.py).
  С обложкой лимит текста 1024 знака, без — 4096.
- **Отложенная публикация**: «🕒 Запланировать» → время кнопкой (сегодня/завтра по часам 9–22, 🔸 — рядом уже есть пост)
  или текстом `15:30` / `28.11 15:30` (МСК, не дальше 30 дней). Очередь — у бота (таблица `post_queue`), в нужную минуту он
  публикует сам (опоздание до ~25 с) и пишет обоим «Вышел запланированный». Если бот лежал дольше 6 часов — просроченный пост
  не публикует, а присылает текст. Ошибка канала — сообщение с текстом, без повторов.
  `/ochered` — список: ⚙️ у поста → 🕒 другое время · ▶️ сейчас · 🗑 убрать. Отложенные Telegram (ручные) бот не видит —
  при планировании проверяй их сам.
- `/post` — подсказка. `POST_MODE=off` — выключить. `YANDEX_POST_MODEL` — модель для переписывания (по умолчанию как у подборки).
