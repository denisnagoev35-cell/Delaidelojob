# Бот «Зарплаты HoReCa» (@delaidelo24bot)

Чистый Python 3.10+, без сторонних библиотек. Данные — SQLite в /opt/ddbot/data.

- `texts.py` — все тексты и цифры зарплат (править здесь).
- `bot.py` — логика.
- Ссылки с меткой источника: `https://t.me/delaidelo24bot?start=vk_clip`
- `/stats` — статистика (для ID из ADMIN_IDS).

Обновить: `cd /opt/ddbot && sudo git pull && sudo systemctl restart ddbot`
Логи: `sudo journalctl -u ddbot -n 50 --no-pager`

## Подборка вакансий (тест, только ADMIN_IDS)

`podbor.py`. Каждый новый пост канала разбирается: профессия, город/метро, ставка, график, опыт.
Сначала YandexGPT (если в /etc/ddbot.env есть `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`), что не нашлось — правилами.
Телефоны, @ники и ссылки в YandexGPT не отправляются. Без ключа всё работает на правилах.

- `/podbor` — опрос и подборка за 7 дней.
- `/reparse [дней]` — разобрать старые посты (по умолчанию 14 дней); ручные правки не трогает.
- `/vac N` — что бот понял из поста №N.
- `/mesto N Химки`, `/stavka N 4000-6000 смена` — поправить вручную.
- Если в новом посте нет места или ставки, бот пишет админу с кнопками.
