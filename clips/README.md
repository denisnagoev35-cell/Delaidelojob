# Клипы: монтаж и оформление

Скрипты, которыми собирались ролики «Три смены бесплатно» (05.11) и «Обещали 6 000 — дали 1 200» (06–07.11).
Шрифты — `../fonts/`, логотип — `../banners/logo.png`. Пути внутри скриптов рассчитаны на рабочую папку,
где рядом лежат `tools/` (эта ветка), кадры клипов и озвучка — при повторном использовании поправить пути.

- `clip1_final.py` — метка канала, водяной знак, пословные субтитры, замена концовки под площадку (ролик 1).
- `clip2_final.py` — то же для ролика 2 + крючок «печать на лоб» с наездом камеры.
- `clip1_overlays.py`, `clip2_overlays.py` (+ `_v1`) — хук, плашки штрафов, штамп, карточка бота, метка.
- `endcard_channel.py` — концовка «@delaidelojob» (vk / youtube / tiktok_dzen); `endcard_bot.py` — концовка «@delaidelo24bot».
- `hook_zoom.py` — наезд камеры на крючок.
- `clip1_assemble.sh`, `clip2_assemble.sh` — склейка сцен Kling с переходами и вставками (ffmpeg).
- PNG — готовые плашки ролика 2 (1080×1920, прозрачный фон).

Стиль субтитров: Montserrat ExtraBold Italic, белый + ключевые слова жёлтым #FFC603, тень, слова по одному
чуть впереди голоса (~0,1 с). Громкость финала — loudnorm −14 LUFS.
